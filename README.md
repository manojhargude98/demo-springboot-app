# Demo Spring Boot Application

This is a simple Spring Boot REST API project created using Spring Tool Suite (STS).

## Tech Stack
- Java 17
- Spring Boot
- Maven

## How to Run
1. Clone the repository
2. Import as Maven project in STS
3. Run `DemoApplication.java`
4. Open browser: http://localhost:8080/hello

## API Endpoints
| Method | Endpoint | Description |
|------|--------|-------------|
| GET | /hello | Sample hello API |
